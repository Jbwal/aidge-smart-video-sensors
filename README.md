# Aidge — Smart Video Sensors

## Overview

This repository contains our work for the Aidge Smart Video Sensors
challenge.

The project focuses on embedded AI and computer vision for intelligent
video sensing under strict hardware and energy constraints.

## Objectives

- Explore person detection and counting.
- Investigate embedded AI deployment.
- Evaluate model performance and computational requirements.
- Study optimization techniques for resource-constrained platforms.
- Document experiments and results.

## Technical Stack

The technologies will be documented as the project progresses.

Potential areas include:
- Python
- Computer Vision
- Deep Learning
- Edge AI
- Model Quantization
- Embedded AI Acceleration

## Repository Structure

- `docs/`: Project documentation.
- `src/`: Source code.
- `models/`: Model configurations and documentation.
- `notebooks/`: Experiments and analysis.
- `scripts/`: Utility and evaluation scripts.
- `tests/`: Automated tests.
- `results/`: Experimental results.
